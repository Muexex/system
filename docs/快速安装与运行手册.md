# 研伴答疑快速安装与运行手册

适用于 **Windows 10／11、64位x64电脑、Git Bash**。命令逐条执行，上一条成功后再继续；遇到错误先处理，不要跳过。

## 1. 安装基础软件

下载安装：

- [Git for Windows](https://git-scm.com/downloads/win)。
- [Node.js 22 LTS](https://nodejs.org/dist/v22.23.3/node-v22.23.3-x64.msi)。当前项目使用22.x，不使用24.x。

Node.js安装时可不勾选“自动安装本机模块所需工具”。安装完成后重新打开Git Bash，检查：

```bash
git --version
node -v
npm -v
```

三条命令应显示版本号，Node.js应为`v22.x.x`。

## 2. 下载网站

```bash
cd ~
git clone https://github.com/Muexex/system.git
cd ~/system
```

若要求GitHub登录，使用有仓库访问权限的账号。若`system`目录已存在，先确认是否为已有项目，不要删除已有数据。

## 3. 安装依赖、初始化数据库

```bash
npm ci
npm run setup
```

看到“初始化完成”后继续。此步骤自动准备配置文件和数据库；重复初始化不清空已有数据，也不创建默认账号。

## 4. 创建管理员

**单独执行**以下命令，不要把后续命令一起粘贴：

```bash
winpty node.exe scripts/admin-create.mjs
```

按提示填写账号、昵称、密码和确认密码。账号为3—32位字母、数字、点、下划线或短横线；密码为10—128个字符。密码输入时不显示字符，属于正常现象。

若Git Bash无法执行，在**PowerShell**中改用：

```powershell
cd "$env:USERPROFILE\system"
npm.cmd run admin:create
```

若提示管理员已初始化，使用现有账号登录；此命令不会重置管理员密码。

## 5. 构建并启动

回到Git Bash的项目目录执行：

```bash
npm run build
npm start
```

启动成功后，在浏览器输入：

```text
首页：http://localhost:3000
管理员：http://localhost:3000/admin/login
```

保持终端打开。停止网站按`Ctrl+C`。

## 6. 开始使用

1. 教师在首页注册教师账号，填写资料。
2. 管理员登录，审核并启用教师、设置可答科目。
3. 教师登录并上线。
4. 学生注册登录，选择科目并提交问题。
5. 教师接受请求，双方进入答疑室交流。
6. 结束答疑后，学生提交反馈。

教师资格限定为成年、非在职的全日制在校大学生或研究生。文字答疑可直接使用；默认音视频区域仅用于本机设备预览，真实双人通话需要另行配置。

## 7. 以后每次启动

无需重新安装或创建管理员，打开Git Bash执行：

```bash
cd ~/system
npm start
```

## 8. 其他电脑或手机访问

网站启动后，在另一个Git Bash窗口执行：

```bash
ipconfig
```

找到当前Wi-Fi或以太网的IPv4地址，例如`192.168.1.20`。同一局域网的其他设备在浏览器访问：

```text
http://192.168.1.20:3000
```

其他设备只需要浏览器。Windows防火墙提示时允许在可信的专用网络访问；必要时允许专用网络TCP端口3000。服务电脑须保持开机、联网并运行网站。这不是公网访问地址。

## 9. 安装报错、不想安装Visual Studio

若`npm ci`提示`better-sqlite3`下载失败，随后要求Visual Studio：

1. [下载官方Windows驱动包](https://github.com/WiseLibs/better-sqlite3/releases/download/v12.11.1/better-sqlite3-v12.11.1-node-v127-win32-x64.tar.gz)，保存到当前用户的“下载”文件夹，保留原文件名，不解压。
2. 在Git Bash的项目目录执行：

```bash
npm_config_better_sqlite3_local_prebuilds="$(cygpath -w "$HOME/Downloads")" npm ci
```

成功后，从第3节的`npm run setup`继续。该驱动包对应当前锁定的better-sqlite3 12.11.1、Node.js 22和Windows x64；其他版本或架构请查阅完整手册。

## 10. 数据保存与迁移

账号和答疑记录保存在`data/dev.db`，图片保存在`data/uploads/`，本机配置保存在`.env`。

重新下载代码不会带来原电脑的数据。迁移时，先停止原电脑的网站，备份并复制`.env`和完整的`data`文件夹到新项目，再初始化、构建并启动。若配置了自定义保存路径，按完整手册调整路径。

多人互相答疑必须访问同一个服务地址。分别访问各自电脑的`localhost`会得到独立的数据，记录不会自动合并。

更新、备份、真实音视频配置及更多故障处理，参见[完整安装与使用手册](使用手册.md)。
